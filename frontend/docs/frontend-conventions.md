# Соглашения по коду фронтенда

Эти правила действуют для исходного кода в `Frontend`.

## Стили и дизайн-система

- Используйте **Tailwind CSS 4**: utility-классы размещаются в `className` компонентов.
- Предпочитайте готовые UI-примитивы **shadcn/ui на Base UI**, а для вариантов компонентов — `cn`/`cva` из `src/shared`.
- Цвета, шрифты и дизайн-токены задаются через CSS-переменные и `@theme inline` в `src/app/globals.css`. Используйте семантические классы `bg-site-surface`, `text-site-text` и другие `site-*`, а не копирование значений цветов.
- Не создавайте `*.module.css` и отдельные CSS-файлы компонентов. `globals.css` предназначен только для импорта Tailwind/shadcn, токенов и необходимого базового оформления.
- Сохраняйте существующие темы, адаптивность, контраст и отсутствие анимаций кнопок. Проверяйте изменения в обеих темах.

## Иконки

- Используйте только локально сгенерированные React-компоненты **Hugeicons Free Stroke Rounded** из `src/shared/lib/icons`.
- Новые иконки загружайте через `pnpm icon <имя-stroke-rounded>` или `pnpm icon <ссылка-на-SVG-Hugeicons-CDN>`.
- Передавайте `aria-hidden="true"` для декоративных иконок и сохраняйте наследование `currentColor`.
- Не используйте Lucide или Hugeicons Pro без согласованной лицензии. MIT-лицензия бесплатных иконок хранится в `src/shared/lib/icons/LICENSE.md`.

## Функции

Объявляйте компоненты, обработчики и вспомогательные функции стрелочными функциями:

```tsx
export const ProjectCard = ({ title }: { title: string }) => {
  return <article>{title}</article>;
};

const handleClick = () => {
  // Действие.
};
```

Не используйте объявления вида `function ProjectCard() {}`.

## Размер и ответственность файла

- В одном файле `.tsx` объявляется только один React-компонент.
- Каждый компонент хранится в отдельном файле. Секция страницы также считается компонентом.
- Данные и типы можно хранить рядом с компонентом либо вынести в отдельные `.ts` файлы.
- Максимум 250 строк в любом исходном `.ts`, `.tsx`, `.css` и `.md` файле.
- Lock-файлы, генерируемые файлы, сторонние зависимости и ассеты не входят в лимит.
- Если файл приближается к лимиту, разделяйте его по назначению до добавления новых функций.

ESLint проверяет стрелочный синтаксис и лимит строк в файлах `.ts` и `.tsx`. Для CSS и Markdown, а также правила «один компонент на файл», соблюдайте соглашение при изменениях и ревью.

## Структура

- `src/app` — маршруты Next.js, layout, провайдеры и глобальные стили.
- `src/widgets` — крупные блоки страниц, включая шапку, подвал и секции.
- `src/features` — действия пользователя и сценарии.
- `src/entities` — предметные сущности.
- `src/shared` — переиспользуемые UI-компоненты и утилиты.

Маршрут `src/app/page.tsx` собирает главную страницу из компонентов виджетов. Общие элементы выносятся так, чтобы их можно было использовать на следующих страницах.
