# 02. Workflow задачи

## Обязательный цикл

Для любой нетривиальной задачи:

1. Прочитать правила
2. Собрать контекст
3. Записать план в `tasks/todo.md`
4. Уточнить неоднозначности
5. Реализовать
6. Проверить
7. Обновить `tasks/todo.md`
8. После коррекции пользователя обновить `tasks/lessons.md`

## Когда нужен plan

План обязателен, если:

- задача больше чем на 2 шага;
- затрагивается несколько файлов;
- есть архитектурное решение;
- есть риск регрессии;
- меняется shared код;
- переписываются правила или документация процесса.

## `tasks/todo.md`

Использовать для:

- checklist задачи;
- spec;
- review;
- фиксации фактических проверок.

## `tasks/lessons.md`

Обновлять после пользовательской коррекции, если можно вывести новое общее правило.

Формат записи:

- дата;
- паттерн ошибки;
- предотвращающее правило.
