# 00. Обзор

## Что это за проект

Проект построен на:

- Next.js 16
- TypeScript
- Feature-Sliced Design

## Главная идея governance

В проекте используется модель context engineering:

- агент не читает весь репозиторий без необходимости;
- правила разбиты на маленькие документы;
- рабочая память задачи отделена от reference memory;
- решение считается хорошим только если оно минимально, проверяемо и контекстно согласовано.

## Где что хранится

- `AGENTS.md` — краткий входной контракт
- `docs/` — reference docs по темам
- `tasks/todo.md` — текущий план и review
- `tasks/lessons.md` — память повторяемых ошибок и пользовательских коррекций

## Обязательный минимум

Всегда должны сохраняться:

- FSD import direction
- именованные экспорты
- правило `один файл = один компонент`
- типизация и `types.ts`, когда это уместно
- verification перед завершением
