# 09. Тестирование и verification

## Базовое правило

Задача не считается завершенной без доказательства корректности.

## Минимум перед завершением

- review изменений;
- локальная проверка;
- запись результата проверки в `tasks/todo.md`.

## Что запускать

В зависимости от scope:

- `npm run lint`
- `npx eslint <files>`
- `npm run type-check`
- `npx tsc --noEmit`
- `npm test`
- таргетированные тесты

## Если полной проверки нет

Нужно явно указать:

- что было проверено;
- что не было проверено;
- какой остаточный риск остается.

## Тестовый принцип

Если изменение затрагивает поведение, а тестов нет, агент должен хотя бы оценить, где уместен тест и почему его нет в текущем scope.
